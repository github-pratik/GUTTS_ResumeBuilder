📥 IMPORT OLD RESUME
Open the student's old resume (Word doc or PDF), select all the text (Ctrl/Cmd+A), copy it, and paste it below. This pulls in only the per-student pieces — name, education, relevant info, any extra skills, and real additional work history — and adds them on top of whichever HVAC/Plumbing template is loaded (auto-detected from the text when possible). Profile Summary, Certifications, base Technical/Soft Skills, and the GUTTS pre-apprenticeship job entry always stay from the template — they're common to every resume in a program, not pulled from the old resume. Phone/email always stay GUTTS' own too. Import into a fresh session per student, and always review before exporting.
